Project Overview

This project demonstrates how AI-powered prompt engineering can help create SEO-friendly blog content and content strategies for a local business.

Business Name: Priya Beauty Studio
Industry: Beauty Salon
Location: Shivamogga, Karnataka, India

Project Objectives

- Generate SEO-friendly blog outlines and articles.
- Identify primary and secondary keywords.
- Create pillar and supporting blogs.
- Develop content clusters and internal linking strategies.
- Adapt content for local SEO.
- Create reusable SEO prompts.

- ChatGPT – AI content generation and prompt engineering.
- Google Docs – Content writing and organisation.
- GitHub – Project documentation and storage.
